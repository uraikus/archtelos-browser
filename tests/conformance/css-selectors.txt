# Selectors this instrument asks both engines about, one per line, run
# against tests/fixtures/selectors.html. A selector counts as
# implemented when it matches exactly the elements Chromium matches --
# not merely when it parses.
#
# The list is Selectors 3's own feature set plus every part of
# Selectors 4 this fixture can grade without being changed, so the count
# says what is left rather than only what works. The number that passes
# may not go down (CLAUDE.md §2); adding a row that fails is how the
# denominator grows, and is the point.
#
# A selector that matches nothing in the fixture proves nothing: an
# engine that drops it agrees with one that implements it. Every
# selector here matches at least one element in Chromium, and
# tests/run.sh fails the run if that stops being true.
#
# A blank line is skipped, and so is a comment -- which is "# " or a
# bare "#", with the space required, because "#p1" is an id selector.

# --- Selectors 4: a complex selector inside :is(), :where(), :not()
# and :has(). Each takes a <complex-selector-list> in §3.1, not a
# compound, and :has() takes a relative selector -- so a leading
# combinator in it names a child or a sibling rather than a descendant.
:is(div > p)
:where(div > p)
p:not(div > p)
:is(h2):is(#h1)
:not(:not(p))
div:has(> p)
div:has(+ div)
p:has(+ p)
li:has(~ li)
div:not(:has(p))
# `:is()` and `:where()` take a forgiving selector list (§3.1): an
# alternative neither engine can read is dropped and the rest still
# work. `:not()` and `:has()` do not -- but an invalid selector matches
# nothing in Chromium, so those cannot be rows here and the unit suite
# asserts them instead.
:is(p, &&&bogus)
:where(p, &&&bogus)
:is(p, :totally-unknown)
:is(p, > span)
p:is(:nth-child(1), .lead)

# One `:has()` may name two relations, which Chromium answers both of
div:has(> p, + div)
# and a relative selector may be complex under its own relation
ul:has(> li + li)

# --- Selectors 4: :nth-child()'s `of S` clause, which filters which
# siblings are counted before An+B is applied to them. `S` is a whole
# complex selector list, and only :nth-child() and :nth-last-child()
# take one -- `:nth-of-type(1 of p)` is a syntax error in Chromium.
p:nth-child(2 of .lead)
:nth-child(1 of p)
li:nth-child(even of :not(.x))
:nth-child(2n of li)
:nth-child(odd of li)
:nth-child(-n+2 of li)
:nth-last-child(1 of p)
:nth-last-child(2 of li)
:nth-child(1 of .lead, .tail)
:nth-child(2 of div > p)
li:nth-child(1 of li:not(:first-child))
p:nth-child(1 of :is(.lead, .tail))
