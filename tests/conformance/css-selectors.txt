# Selectors this instrument asks both engines about, one per line, run
# against tests/fixtures/selectors.html. A selector counts as
# implemented when it matches exactly the elements Chromium matches --
# not merely when it parses.
#
# The list is Selectors 3's own feature set plus the parts of Selectors
# 4 the snapshot's lowest class mentions, so the count says what is left
# rather than only what works. It may not go down (CLAUDE.md §2).
#
# A selector that matches nothing in the fixture proves nothing: an
# engine that drops it agrees with one that implements it. Every
# selector here matches at least one element in Chromium, and
# tests/run.sh fails the run if that stops being true.
#
# A blank line is skipped, and so is a comment -- which is "# " or a
# bare "#", with the space required, because "#p1" is an id selector.
